# Contributing

Contributions should preserve stable chapter routes and anchors. Mathematical changes must cite a primary source, state assumptions, and include a reproducible check whenever the claim is computational. New exercises require an answer or rubric in the public solutions companion.

A chapter moves through `draft`, `technical-review`, `pedagogical-review`, `copy-edit`, and `verified`. The technical and pedagogical reviewers must be independent people and must record their approval in the chapter review manifest. Authors may not approve their own work.

Do not commit private source extracts, Kaggle credentials, copyrighted textbook scans, or source excerpts without a permissions record. Run `npm run check` before opening a pull request.
